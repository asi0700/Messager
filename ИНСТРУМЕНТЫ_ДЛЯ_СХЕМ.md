# Инструменты для создания схем и диаграмм

## Рекомендуемые сайты для визуализации

### 1. Mermaid Live Editor ⭐ (РЕКОМЕНДУЕТСЯ)
**URL**: https://mermaid.live/

**Описание**: Онлайн-редактор для создания диаграмм на основе текстового синтаксиса Mermaid.

**Преимущества**:
- ✅ Бесплатный
- ✅ Не требует регистрации
- ✅ Простой текстовый синтаксис
- ✅ Поддерживает множество типов диаграмм
- ✅ Можно экспортировать в PNG, SVG, PDF
- ✅ Можно сохранить код в GitHub Gist

**Поддерживаемые типы диаграмм**:
- Flowchart (блок-схемы)
- Sequence diagrams (последовательности)
- Gantt charts (диаграммы Ганта)
- ER diagrams (ER-диаграммы)
- Class diagrams (диаграммы классов)
- State diagrams (диаграммы состояний)
- И многое другое

**Как использовать**:
1. Откройте https://mermaid.live/
2. Вставьте код из файлов документации
3. Диаграмма отобразится автоматически
4. Нажмите "Actions" → "Download PNG/SVG" для сохранения

---

### 2. Draw.io (diagrams.net)
**URL**: https://app.diagrams.net/

**Описание**: Мощный онлайн-редактор диаграмм с большим количеством шаблонов.

**Преимущества**:
- ✅ Полностью бесплатный
- ✅ Не требует регистрации (можно сохранить в облаке)
- ✅ Огромная библиотека элементов
- ✅ Поддержка импорта/экспорта различных форматов
- ✅ Можно сохранить в Google Drive, OneDrive, GitHub

**Поддерживаемые форматы**:
- Собственный формат .drawio
- PNG, JPG, SVG, PDF
- XML, JSON
- VSDX (Visio)

**Как использовать**:
1. Откройте https://app.diagrams.net/
2. Выберите место сохранения (Device, Google Drive и т.д.)
3. Создайте новую диаграмму или импортируйте существующую
4. Используйте элементы из панели слева
5. Сохраните через File → Export as → PNG/SVG/PDF

---

### 3. dbdiagram.io
**URL**: https://dbdiagram.io/

**Описание**: Специализированный инструмент для создания ER-диаграмм баз данных.

**Преимущества**:
- ✅ Бесплатный (с ограничениями)
- ✅ Специализирован для БД
- ✅ Простой синтаксис DBML
- ✅ Автоматическая генерация SQL
- ✅ Красивое визуальное представление

**Как использовать**:
1. Откройте https://dbdiagram.io/
2. Вставьте код DBML из файла СХЕМА_БД.md
3. Диаграмма отобразится автоматически
4. Можно экспортировать в PNG или PDF

---

### 4. Lucidchart
**URL**: https://www.lucidchart.com/

**Описание**: Профессиональный инструмент для создания диаграмм (платный, есть бесплатный план).

**Преимущества**:
- ✅ Очень мощный и функциональный
- ✅ Множество шаблонов
- ✅ Интеграция с различными сервисами
- ⚠️ Ограниченный бесплатный план

**Как использовать**:
1. Зарегистрируйтесь (есть бесплатный план)
2. Создайте новый документ
3. Используйте элементы из библиотеки
4. Экспортируйте в PNG, PDF, SVG

---

### 5. PlantUML Online
**URL**: http://www.plantuml.com/plantuml/uml/

**Описание**: Онлайн-редактор для PlantUML (текстовый синтаксис для UML диаграмм).

**Преимущества**:
- ✅ Бесплатный
- ✅ Текстовый синтаксис
- ✅ Поддержка различных типов UML диаграмм
- ✅ Можно экспортировать в PNG, SVG

**Как использовать**:
1. Откройте http://www.plantuml.com/plantuml/uml/
2. Вставьте код PlantUML
3. Диаграмма сгенерируется автоматически
4. Сохраните изображение

## Рекомендации по использованию

### Для блок-схем проекта:
**Лучший выбор**: **Mermaid Live Editor** или **Draw.io**
- Mermaid: быстрый, простой синтаксис
- Draw.io: больше контроля, визуальное редактирование

### Для диаграммы Ганта:
**Лучший выбор**: **Mermaid Live Editor**
- Отличная поддержка Gantt charts
- Простой синтаксис

### Для схемы базы данных:
**Лучший выбор**: **dbdiagram.io** или **Mermaid Live Editor**
- dbdiagram.io: специализирован для БД, красивое представление
- Mermaid: универсальный, поддерживает ER-диаграммы

### Для структуры проекта:
**Лучший выбор**: **Draw.io** или текстовый формат (Markdown)
- Draw.io: можно создать визуальное дерево
- Markdown: уже готово в файле СТРУКТУРА_ПРОЕКТА.md
