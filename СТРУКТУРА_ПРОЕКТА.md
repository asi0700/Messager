 Детальная структура пакетов

 com.example.first_project.activity

Содержит все Activity (экраны) приложения:

```
activity/
├── SplashActivity.java           # Экран загрузки, проверка авторизации
├── RegistrationActivity.java    # Регистрация нового пользователя
├── LoginActivity.java           # Вход в аккаунт
├── UsernameActivity.java        # Установка имени пользователя
├── MainActivity.java            # Главный экран (список чатов)
├── ChatListActivity.java        # Альтернативный экран списка чатов
├── ChatActivity.java            # Экран чата (обмен сообщениями)
├── SearchActivity.java          # Поиск пользователей
├── ProfileActivity.java         # Профиль пользователя
├── SecondActivity.java          # Вспомогательная активность
└── ThirdActivity.java          # Вспомогательная активность
```

**Описание Activities:**

- **SplashActivity**: Первый экран при запуске, проверяет авторизацию и перенаправляет
- **RegistrationActivity**: Форма регистрации с валидацией
- **LoginActivity**: Форма входа в аккаунт
- **UsernameActivity**: Установка username после регистрации
- **MainActivity**: Главный экран со списком чатов, поиском и меню
- **ChatActivity**: Экран чата с отправкой текста и изображений
- **SearchActivity**: Поиск пользователей по username
- **ProfileActivity**: Просмотр и редактирование профиля

### com.example.first_project.adapter

RecyclerView адаптеры для отображения списков:

```
adapter/
├── ChatsAdapter.java            # Адаптер для списка чатов
├── MessageAdapter.java         # Адаптер для списка сообщений
└── UsersAdapter.java           # Адаптер для списка пользователей
```

**Описание адаптеров:**

- **ChatsAdapter**: Отображает список чатов с именем, последним сообщением и временем
- **MessageAdapter**: Отображает сообщения в чате (текст и изображения)
- **UsersAdapter**: Отображает результаты поиска пользователей

### com.example.first_project.model

Модели данных (POJO классы):

```
model/
├── User.java                    # Модель пользователя
├── Chat.java                    # Модель чата
├── ChatItem.java                # Элемент списка чатов
└── Message.java                 # Модель сообщения
```

**Описание моделей:**

- **User**: Информация о пользователе (userId, email, username, profileImage, status)
- **Chat**: Информация о чате (chatId, participants, lastMessage, timestamps)
- **ChatItem**: Упрощенная модель для отображения в списке чатов
- **Message**: Информация о сообщении (senderId, text, timestamp, type, imageUrl)

 Зависимости проекта

 Основные библиотеки (из libs.versions.toml):

- **AndroidX Libraries**:
  - `appcompat` - Поддержка совместимости
  - `material` - Material Design компоненты
  - `activity` - Activity компоненты
  - `constraintlayout` - Constraint Layout

- **Firebase**:
  - `firebase-auth` - Аутентификация
  - `firebase-database` - Realtime Database
  - `firebase-storage` - Хранилище файлов
  - `firebase-firestore` - Firestore (не используется активно)

- **Другие**:
  - `glide` - Загрузка и кэширование изображений
  - `credentials` - Управление учетными данными

 Конфигурационные файлы

 AndroidManifest.xml
Определяет:
- Разрешения (INTERNET, ACCESS_NETWORK_STATE, READ_EXTERNAL_STORAGE, READ_MEDIA_IMAGES)
- Activities и их конфигурацию
- Точка входа (SplashActivity)

 build.gradle.kts (app)
- Минимальная версия SDK: 24 (Android 7.0)
- Целевая версия SDK: 36
- Версия приложения: 1.0

 google-services.json
Конфигурация Firebase проекта:
- Database URL: `https://messenger-86a14-default-rtdb.europe-west1.firebasedatabase.app`
- Storage bucket
- Authentication settings

 Архитектурные паттерны

1. **MVC (Model-View-Controller)**:
   - Model: классы в пакете `model`
   - View: XML layout файлы
   - Controller: Activities

2. **Adapter Pattern**:
   - RecyclerView адаптеры для списков

3. **Observer Pattern**:
   - Firebase listeners (ValueEventListener) для обновлений в реальном времени

## Потоки данных

1. **Аутентификация**: Firebase Auth → Activities
2. **Данные пользователей**: Firebase Realtime Database ↔ Activities
3. **Сообщения**: Firebase Realtime Database ↔ ChatActivity
4. **Изображения**: Firebase Storage ↔ Activities (через Glide)

 Особенности реализации

1. **Обработка статуса онлайн/офлайн**: 
   - Обновление в `onResume()` и `onPause()` MainActivity

2. **Создание чатов**:
   - ChatId формируется как `userId1_userId2` (отсортированные)

3. **Загрузка изображений**:
   - Используется ActivityResultLauncher для выбора изображений
   - Загрузка в Firebase Storage с уникальными именами

4. **Поиск пользователей**:
   - Поиск по username с использованием Firebase queries
