# Документация проекта Messager

## Обзор

Этот документ содержит полную документацию для Android мессенджер-приложения **Messager**. Документация включает руководство пользователя, технические схемы, структуру проекта и инструкции по визуализации.

## Быстрый старт

### Для пользователей:
1. Откройте `РУКОВОДСТВО_ПОЛЬЗОВАТЕЛЯ.md`
2. Следуйте инструкциям по установке и использованию

### Для разработчиков:
1. Изучите `СТРУКТУРА_ПРОЕКТА.md` для понимания архитектуры
2. Просмотрите `СХЕМА_БД.md` для работы с базой данных
3. Используйте `БЛОК_СХЕМА_ПРОЕКТА.md` для понимания логики

### Для визуализации схем:
1. Откройте `ИНСТРУМЕНТЫ_ДЛЯ_СХЕМ.md`
2. Выберите подходящий инструмент
3. Скопируйте код из соответствующих файлов
4. Вставьте в выбранный инструмент
5. Сохраните изображение

## Рекомендуемые инструменты

### ⭐ Mermaid Live Editor (РЕКОМЕНДУЕТСЯ)
**URL**: https://mermaid.live/

**Используйте для**:
- Блок-схем
- Диаграмм Ганта
- ER-диаграмм
- Любых других диаграмм Mermaid

**Преимущества**: Бесплатный, простой, не требует регистрации

### Draw.io
**URL**: https://app.diagrams.net/

**Используйте для**:
- Сложных визуальных диаграмм
- Ручного создания схем
- Импорта/экспорта различных форматов

### dbdiagram.io
**URL**: https://dbdiagram.io/

**Используйте для**:
- Специализированных схем баз данных
- Автоматической генерации SQL

## Дополнительная информация

### Технологии проекта:
- **Платформа**: Android (API 24+)
- **Язык**: Java
- **Backend**: Firebase (Auth, Realtime Database, Storage)
- **Архитектура**: MVC

### Основные функции:
- ✅ Регистрация и авторизация
- ✅ Обмен текстовыми сообщениями
- ✅ Отправка изображений
- ✅ Поиск пользователей
- ✅ Создание чатов
- ✅ Профиль пользователя
- ✅ Статус онлайн/офлайн
