 Основной поток приложения (Mermaid)

```mermaid
flowchart TD
    Start([Запуск приложения]) --> Splash[SplashActivity]
    Splash --> CheckAuth{Пользователь<br/>авторизован?}
    
    CheckAuth -->|Да| Main[MainActivity<br/>Список чатов]
    CheckAuth -->|Нет| Reg[RegistrationActivity<br/>Регистрация]
    
    Reg --> Validate{Валидация<br/>данных}
    Validate -->|Ошибка| Reg
    Validate -->|Успех| CreateUser[Создание пользователя<br/>Firebase Auth]
    CreateUser --> Username[UsernameActivity<br/>Установка username]
    Username --> SaveUser[Сохранение в БД]
    SaveUser --> Main
    
    Main --> Menu{Действие}
    Menu -->|Профиль| Profile[ProfileActivity]
    Menu -->|Выход| Logout[Выход из аккаунта]
    Menu -->|Новый чат| Search[SearchActivity<br/>Поиск пользователей]
    Menu -->|Открыть чат| Chat[ChatActivity]
    
    Logout --> Reg
    
    Search --> SearchUser[Поиск по username]
    SearchUser --> SelectUser{Выбор<br/>пользователя}
    SelectUser --> CreateChat[Создание чата]
    CreateChat --> Chat
    
    Chat --> SendMsg{Действие}
    SendMsg -->|Текст| SendText[Отправка текста]
    SendMsg -->|Изображение| PickImage[Выбор изображения]
    PickImage --> Upload[Загрузка в Storage]
    Upload --> SendImage[Отправка изображения]
    SendText --> UpdateChat[Обновление чата]
    SendImage --> UpdateChat
    UpdateChat --> Chat
    
    Profile --> EditProfile{Редактирование}
    EditProfile -->|Аватар| ChangeAvatar[Выбор аватара]
    EditProfile -->|Данные| EditData[Редактирование данных]
    ChangeAvatar --> UploadAvatar[Загрузка аватара]
    UploadAvatar --> UpdateProfile[Обновление профиля]
    EditData --> UpdateProfile
    UpdateProfile --> Profile
    
    style Start fill:#90EE90
    style Main fill:#87CEEB
    style Chat fill:#FFB6C1
    style Profile fill:#DDA0DD
```

## Детальная блок-схема процесса отправки сообщения

```mermaid
flowchart TD
    Start([Пользователь вводит<br/>сообщение]) --> CheckEmpty{Поле<br/>пустое?}
    CheckEmpty -->|Да| End1([Ничего не делать])
    CheckEmpty -->|Нет| GetUser[Получить текущего<br/>пользователя]
    
    GetUser --> CreateMsg[Создать объект Message]
    CreateMsg --> GenerateId[Сгенерировать messageId]
    GenerateId --> PrepareData[Подготовить данные<br/>для Firebase]
    PrepareData --> SetTimestamp[Установить ServerValue.TIMESTAMP]
    SetTimestamp --> SendToDB[Отправить в<br/>Firebase Database]
    
    SendToDB --> Success{Успешно?}
    Success -->|Нет| Error[Показать ошибку]
    Success -->|Да| UpdateLastMsg[Обновить lastMessage<br/>в чате]
    UpdateLastMsg --> UpdateTime[Обновить lastMessagetime]
    UpdateTime --> Notify[Уведомить адаптер]
    Notify --> Scroll[Прокрутить к новому<br/>сообщению]
    Scroll --> ClearField[Очистить поле ввода]
    ClearField --> End2([Готово])
    
    Error --> End2
    
    style Start fill:#90EE90
    style End2 fill:#90EE90
    style Error fill:#FF6B6B
```

## Блок-схема процесса создания чата

```mermaid
flowchart TD
    Start([Пользователь выбирает<br/>собеседника]) --> GetCurrentUser[Получить ID<br/>текущего пользователя]
    GetCurrentUser --> GetOtherUser[Получить ID<br/>собеседника]
    GetOtherUser --> GenerateChatId[Сгенерировать chatId<br/>userId1_userId2]
    
    GenerateChatId --> CheckExists{Чат уже<br/>существует?}
    CheckExists -->|Да| OpenChat[Открыть существующий чат]
    CheckExists -->|Нет| CreateChat[Создать новый чат]
    
    CreateChat --> SetParticipants[Установить участников]
    SetParticipants --> SetNames[Установить имена<br/>участников]
    SetNames --> SetDefaults[Установить значения<br/>по умолчанию]
    SetDefaults --> SaveChat[Сохранить чат в БД]
    
    SaveChat --> AddToUserChats1[Добавить в user_chats<br/>текущего пользователя]
    AddToUserChats1 --> AddToUserChats2[Добавить в user_chats<br/>собеседника]
    AddToUserChats2 --> OpenChat
    
    OpenChat --> Navigate[Перейти в ChatActivity]
    Navigate --> End([Готово])
    
    style Start fill:#90EE90
    style End fill:#90EE90
    style CreateChat fill:#87CEEB
```

## Блок-схема процесса аутентификации

    SetUsername --> Main[MainActivity]
    
    LoadUser --> Main

    style Start fill:#90EE90
    style End fill:#90EE90

## Блок-схема загрузки изображения

```mermaid
flowchart TD
    Start([Нажатие кнопки<br/>вложения]) --> CheckPerm{Проверить<br/>разрешение}
    CheckPerm -->|Нет| RequestPerm[Запросить разрешение]
    RequestPerm --> CheckPerm
    CheckPerm -->|Да| OpenPicker[Открыть выбор<br/>изображения]
    
    OpenPicker --> UserSelect{Пользователь<br/>выбрал?}
    UserSelect -->|Нет| End1([Отмена])
    UserSelect -->|Да| GetUri[Получить URI<br/>изображения]
    
    GetUri --> ShowProgress[Показать прогресс<br/>загрузки]
    ShowProgress --> GenerateName[Сгенерировать<br/>уникальное имя файла]
    GenerateName --> Upload[Загрузить в<br/>Firebase Storage]
    
    Upload --> GetUrl{Получить<br/>URL?}
    GetUrl -->|Ошибка| ShowError[Показать ошибку]
    GetUrl -->|Успех| CreateMsg[Создать сообщение<br/>с imageUrl]
    
    CreateMsg --> SendMsg[Отправить сообщение<br/>в Database]
    SendMsg --> UpdateChat[Обновить lastMessage]
    UpdateChat --> HideProgress[Скрыть прогресс]
    HideProgress --> End2([Готово])
    
    ShowError --> End2
    
    style Start fill:#90EE90
    style End2 fill:#90EE90
    style ShowError fill:#FF6B6B
    style Upload fill:#87CEEB
```



 Описание основных процессов

 1. Запуск приложения
- SplashActivity проверяет авторизацию
- Перенаправляет на MainActivity или RegistrationActivity

 2. Регистрация
- Валидация данных
- Создание аккаунта в Firebase Auth
- Сохранение данных пользователя
- Установка username

 3. Главный экран
- Загрузка списка чатов из Firebase
- Отображение с фильтрацией и поиском
- Обновление статуса онлайн/офлайн

 4. Создание чата
- Поиск пользователя
- Генерация уникального chatId
- Создание записи в базе данных
- Добавление в индексы user_chats

 5. Отправка сообщения
- Создание объекта Message
- Отправка в Firebase Database
- Обновление lastMessage в чате
- Обновление UI

 6. Загрузка изображения
- Проверка разрешений
- Выбор изображения
- Загрузка в Firebase Storage
- Получение URL
- Создание сообщения с imageUrl
