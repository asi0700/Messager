# Руководство по настройке Git и подключению к проекту

## Шаг 1: Установка Git

Если Git не установлен на вашем компьютере:

1. Скачайте Git для Windows: https://git-scm.com/download/win
2. Установите Git, следуя инструкциям установщика
3. Перезапустите терминал/командную строку после установки

## Шаг 2: Настройка Git (первый раз)

Выполните следующие команды для настройки вашего имени и email:

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "ваш.email@example.com"
```

## Шаг 3: Инициализация репозитория (если еще не инициализирован)

Если проект еще не является Git репозиторием, выполните:

```bash
cd C:\Users\MataDoRs\Desktop\Messager-master
git init
```

## Шаг 4: Подключение к удаленному репозиторию

### Вариант A: Если у вас уже есть удаленный репозиторий (GitHub, GitLab, Bitbucket и т.д.)

1. **Добавьте удаленный репозиторий:**
   ```bash
   git remote add origin https://github.com/username/repository.git
   ```
   (Замените URL на адрес вашего репозитория)

2. **Проверьте подключение:**
   ```bash
   git remote -v
   ```

3. **Получите код из удаленного репозитория:**
   ```bash
   git pull origin main
   ```
   (или `master` вместо `main`, в зависимости от вашего репозитория)

### Вариант B: Если нужно создать новый репозиторий на GitHub

1. Создайте новый репозиторий на GitHub (https://github.com/new)
2. Не добавляйте README, .gitignore или лицензию (у вас уже есть файлы)
3. Скопируйте URL репозитория
4. Выполните команды из Варианта A

## Шаг 5: Первый коммит (если проект новый)

Если это новый репозиторий, добавьте все файлы и сделайте первый коммит:

```bash
git add .
git commit -m "Initial commit"
```

## Шаг 6: Отправка изменений в удаленный репозиторий

После внесения изменений в проект:

1. **Проверьте статус изменений:**
   ```bash
   git status
   ```

2. **Добавьте измененные файлы:**
   ```bash
   git add .
   ```
   или для конкретных файлов:
   ```bash
   git add путь/к/файлу
   ```

3. **Создайте коммит:**
   ```bash
   git commit -m "Описание ваших изменений"
   ```

4. **Отправьте изменения в удаленный репозиторий:**
   ```bash
   git push origin main
   ```
   (или `master` вместо `main`)

## Шаг 7: Получение изменений от других разработчиков

Перед началом работы всегда получайте последние изменения:

```bash
git pull origin main
```

## Работа с ветками (Branch)

### Создание новой ветки для ваших изменений:

```bash
git checkout -b название-вашей-ветки
```

### Переключение между ветками:

```bash
git checkout название-ветки
```

### Отправка ветки в удаленный репозиторий:

```bash
git push origin название-вашей-ветки
```

## Полезные команды

- `git status` - показать статус изменений
- `git log` - показать историю коммитов
- `git diff` - показать различия в файлах
- `git branch` - показать список веток
- `git remote -v` - показать подключенные удаленные репозитории

## Решение проблем

### Если нужно изменить URL удаленного репозитория:
```bash
git remote set-url origin новый-URL
```

### Если нужно удалить удаленный репозиторий:
```bash
git remote remove origin
```

### Если возникли конфликты при pull:
1. Git покажет файлы с конфликтами
2. Откройте файлы и разрешите конфликты вручную
3. После разрешения:
   ```bash
   git add .
   git commit -m "Resolve conflicts"
   ```

## Аутентификация

При первом `push` или `pull` Git может запросить ваши учетные данные:
- Для GitHub: используйте Personal Access Token вместо пароля
- Для GitLab: используйте Personal Access Token
- Для Bitbucket: используйте App Password

### Создание Personal Access Token на GitHub:
1. Перейдите в Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Нажмите "Generate new token"
3. Выберите необходимые права доступа
4. Скопируйте токен и используйте его как пароль при аутентификации
