Руководство пользователя - Messager

Описание приложения

**Messager** - это мобильное мессенджер-приложение для Android, позволяющее пользователям обмениваться текстовыми сообщениями и изображениями в реальном времени. Приложение использует Firebase для аутентификации, хранения данных и файлов.

 Системные требования

- Android версии 7.0 (API 24) или выше
- Активное интернет-соединение
- Разрешения на доступ к интернету и хранилищу (для отправки изображений)

 Установка

1. Скачайте APK-файл приложения
2. Разрешите установку из неизвестных источников в настройках Android
3. Установите приложение, следуя инструкциям на экране

 Первый запуск

 Регистрация нового пользователя

1. При первом запуске приложения откроется экран **SplashActivity** (экран загрузки)
2. Если вы не авторизованы, автоматически откроется экран **RegistrationActivity**
3. Заполните форму регистрации:
   - **Email**: введите ваш адрес электронной почты
   - **Пароль**: создайте пароль (минимум 6 символов)
   - **Подтверждение пароля**: введите пароль повторно
4. Нажмите кнопку **"Зарегистрироваться"**
5. После успешной регистрации вы будете перенаправлены на экран **UsernameActivity** для установки имени пользователя

Вход в существующий аккаунт

1. На экране регистрации нажмите на ссылку **"Войти"**
2. Введите ваш email и пароль
3. Нажмите кнопку **"Войти"**
4. После успешного входа откроется главный экран приложения

 Основные функции

 Главный экран (MainActivity)

Главный экран отображает список всех ваших чатов.

**Элементы интерфейса:**
- **Поиск**: строка поиска вверху для фильтрации чатов по имени
- **Список чатов**: отображает все ваши активные чаты с:
  - Именем собеседника
  - Последним сообщением
  - Временем последнего сообщения
  - Индикатором онлайн-статуса (зеленый индикатор для онлайн пользователей)
- **Кнопка "+" (FAB)**: создание нового чата
- **Меню** (три точки в правом верхнем углу):
  - **Профиль**: переход к вашему профилю
  - **Выход**: выход из аккаунта

**Функции:**
- Нажмите на чат, чтобы открыть его
- Используйте поиск для быстрого нахождения нужного чата
- Чаты автоматически сортируются по времени последнего сообщения (новые сверху)

 Создание нового чата

1. На главном экране нажмите кнопку **"+"** (плавающая кнопка в правом нижнем углу)
2. Откроется экран **SearchActivity** для поиска пользователей
3. Введите имя пользователя в строку поиска
4. В списке результатов выберите нужного пользователя
5. Чат будет создан автоматически, и вы перейдете в него

 Чат (ChatActivity)

Экран чата позволяет обмениваться сообщениями с другим пользователем.

**Элементы интерфейса:**
- **Заголовок**: имя собеседника
- **Список сообщений**: прокручиваемый список всех сообщений в чате
- **Поле ввода**: для ввода текстового сообщения
- **Кнопка отправки**: отправка текстового сообщения
- **Кнопка вложения**: прикрепление изображения к сообщению
- **Кнопка "Назад"**: возврат к списку чатов

**Функции:**
- **Отправка текстового сообщения**:
  1. Введите текст в поле ввода
  2. Нажмите кнопку отправки или клавишу Enter
  3. Сообщение появится в чате справа (ваши сообщения) или слева (сообщения собеседника)

- **Отправка изображения**:
  1. Нажмите кнопку вложения (скрепка)
  2. Разрешите доступ к изображениям, если приложение запросит разрешение
  3. Выберите изображение из галереи
  4. Изображение автоматически загрузится и отправится в чат

**Особенности:**
- Сообщения отображаются с временем отправки
- Ваши сообщения отображаются справа с синим фоном
- Сообщения собеседника отображаются слева с серым фоном
- Чат автоматически прокручивается к новым сообщениям
- Сообщения загружаются в реальном времени

 Профиль пользователя (ProfileActivity)

Экран профиля позволяет просматривать и редактировать информацию о вашем аккаунте.

**Отображаемая информация:**
- **Аватар**: фотография профиля (можно изменить)
- **Имя пользователя**: ваш никнейм
- **Email**: адрес электронной почты
- **ID пользователя**: уникальный идентификатор
- **Дата регистрации**: когда был создан аккаунт

**Функции:**
- **Изменение аватара**:
  1. Нажмите на изображение аватара
  2. Выберите изображение из галереи
  3. Изображение автоматически загрузится и обновится

- **Редактирование профиля**:
  1. Нажмите кнопку **"Редактировать профиль"**
  2. В открывшемся окне можно изменить:
     - Имя пользователя
     - Статус
     - Отображаемое имя
  3. Нажмите **"Сохранить"** для применения изменений

 Поиск пользователей (SearchActivity)

Экран поиска позволяет находить других пользователей для создания чата.

**Функции:**
- Введите имя пользователя в строку поиска
- Результаты поиска отображаются в реальном времени
- Нажмите на пользователя в списке, чтобы создать с ним чат
- Если чат с этим пользователем уже существует, вы перейдете в него

 Статус онлайн/офлайн

Приложение автоматически отслеживает ваш статус:
- **Онлайн**: когда приложение активно (onResume)
- **Офлайн**: когда приложение свернуто или закрыто (onPause)

Статус других пользователей отображается в списке чатов зеленым индикатором.

 Безопасность

- Все данные хранятся в защищенной базе данных Firebase
- Пароли шифруются и не хранятся в открытом виде
- Аутентификация выполняется через Firebase Authentication
- Изображения загружаются в защищенное хранилище Firebase Storage

 Решение проблем

 Не могу войти в аккаунт
- Проверьте правильность ввода email и пароля
- Убедитесь, что у вас есть активное интернет-соединение
- Если забыли пароль, используйте функцию восстановления пароля Firebase

 Сообщения не отправляются
- Проверьте интернет-соединение
- Убедитесь, что у приложения есть разрешение на доступ к интернету
- Перезапустите приложение

 Изображения не загружаются
- Проверьте разрешение на доступ к изображениям в настройках приложения
- Убедитесь, что у вас есть активное интернет-соединение
- Проверьте размер изображения (слишком большие файлы могут загружаться долго)

 Чаты не отображаются
- Проверьте интернет-соединение
- Перезапустите приложение
- Убедитесь, что вы авторизованы в системе
